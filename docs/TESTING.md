# Testing

SPEC.md §33 is the normative regression strategy. This file records what runs today, how to run
it, and which required tests belong to which later phase.

## Runtimes

The shared contract is implemented **three times** — Kotlin, Swift, Python — against the *same*
repository-root artifacts. That is not duplication for its own sake: §37.1 requires the
platforms to stay aligned through shared fixtures rather than copied assumptions, and §9.1
requires `analysis/` to agree with both platforms exactly. Identifiers are identical across
runtimes (`INV-01-…`…`INV-11-…`, `RS-01-…`…`RS-11-…`) so a failure reads the same everywhere.

| Runtime | Location | Runs today |
|---|---|---|
| Python | `analysis/tests` | yes — 330 tests |
| Kotlin / JVM | `android/heading-core/src/test`, `android/fengshui-core/src/test` | yes — 193 tests |
| Swift | `ios/HeadingCore/Tests`, `ios/FengShuiCore/Tests` | **no** — no Swift toolchain here, and none installable (deviation D-3) |

## Commands

```bash
# One-time: pinned analysis environment
python3 -m venv .venv-analysis
.venv-analysis/bin/pip install -r analysis/requirements-lock.txt
.venv-analysis/bin/pip install -e analysis

# The whole Phase 1 exit gate (exits non-zero while an exit criterion is unmet)
scripts/ci-phase1.sh

# The Phase 0 gate on its own
scripts/ci-phase0.sh

# Individually
.venv-analysis/bin/python -m pytest analysis/tests -q
.venv-analysis/bin/python scripts/generate-shared-fixtures.py --check   # fixtures-v1 freeze
scripts/validate-fixtures.sh                                            # JSON Schema 2020-12
scripts/verify-artifacts.sh                                             # pins, debug-only providers, NOAA hashes
cd android && ./gradlew :heading-core:test :fengshui-core:test -PfscIncludeAndroidModules=false
cd android && ./gradlew :heading-core:test :fengshui-core:test :app:assembleDebug   # needs the Android SDK
cd ios && swift test                                                    # needs a Swift toolchain
```

`scripts/generate-shared-fixtures.py` regenerates the derived `testdata/` fixtures. Every
expectation in it is computed from the **specification formula written inline**, never by
calling `fscompass_analysis`: a fixture generated by the implementation it polices proves only
that the implementation agrees with itself.

`scripts/generate-scorecard.sh` deliberately **refuses**: there is no benchmark telemetry, so
any output would be a fabricated accuracy claim (§30.1, §37 rule 11).

## What Phase 1 covers

Phase 0's coverage (§4.1 layout, §8.1, §8.1.1, §20 grade totality, §21.1 ruleset geometry, §22
schema validation, R62, §2 pinned versions) still runs. Phase 1 adds:

- **§9 / §9.1** — `normalize360`, the single allowlisted `shortestSignedDifferenceDeg` and its
  exact delegating wrappers, circular mean/resultant, the pinned nearest-rank quantile and
  median, `boundFromSigma`. Both orderings of three distinct antipodal pairs; the `(-180, 180]`
  range swept over the circle; nonfinite rejection; typed `UNDEFINED` on empty input.
- **§33.1 R67/R68** — a per-runtime audit that each executable runtime has exactly one
  signed-difference implementation, that `atan2` appears only in allowlisted
  bearing-projection/circular-mean files, and that no local `deltaDeg` alias exists. The audit
  reads production source sets only, so `SPEC.md`'s prose and the discrimination test that
  deliberately computes the prohibited formula both stay legal, as §33.1 requires.
- **§3 / §11.1 / §14** — quaternion `xyzw` order and transform direction as types; canonical
  device→REFERENCE_ENU attitude with native-frame provenance; N/E/S/W golden poses per mode;
  the two independent extraction routes agreeing (`transformAgreementDeg` ≈ 0); the Core Motion
  native conversion under its declared (unverified) convention; ill-conditioned axis rejection.
- **§11** — the four resolver branches, `correctionDeg ∈ {0, +d}` as a constructor invariant,
  the `2 × declination` signature, the absence of a declination dead band swept across the
  small-declination range, and the explicit iOS / AND-RV contracts rather than the Google
  resolver fed fabricated inputs.
- **§16** — the positive-down inclination conversion including a test that the *missing* minus
  sign would reject a clean northern field; the fused classifier; absent-feature → `UNKNOWN`;
  and R59's acyclicity, checked by sweeping `pipelineAgreementDeg` across its whole range and
  asserting the precheck does not move.
- **§19** — both bounds, `max` over present base terms with absence ≠ zero, R63 monotonicity
  swept over the term's range, the `SUSPECT` freehand-lock impossibility, policy-ceiling
  precedence and the stable-enum-order tie rule.
- **§24 / §19.1** — key construction, rejection of open-ended identities, the
  `NOT_RUNTIME_OBSERVABLE` sentinel, an empty shipped database, `miss → CANDIDATE`, each named
  key component demonstrated to differentiate, and the `CALIBRATED ⇔ EMPIRICALLY_CALIBRATED`
  invariant enforced on construction.
- **§19.3** — production state fixed to `NONE`, `UNIT` scope never `CALIBRATED`, exactly-once
  application.
- **§21** — 216 per-sector probes (centre, both boundaries, ±ε, ±0.1°, ±1.0°), straddle sets
  including the full-circle degenerate case and the near-full-circle case, and §21.2 under both
  hidden Google hypotheses × both declination signs × both ruleset references.
- **§22.2** — the codec in both directions: nonfinite rejection, `lowerCamelCase` keys at any
  depth, the fixed event-type namespace, RFC 3339 UTC, integer monotonic time, round-trip
  precision, the units-in-names rule, and the export path under a comma-decimal locale.
- **§18.2 / §18.5** — the reducer: determinism, lock/degraded/invalid as three outcomes, a
  timeout emitting no measurement, `DISTURBED` clearing a live lock, every invalidating event
  resetting the window, and `PROVIDER_INITIALIZING` distinct from `CALIBRATION_CHECK`.
- **§8.1 INV-11** — the periodic-vs-event-driven sampling invariant (R52).
- **§37.1** — the `fixtures-v1` freeze: a hash manifest covering every shared artifact, every
  hash checked against the bytes on disk, and the generator proven to reproduce its output.

### Discrimination tests

A gate that cannot fail is not a gate. Each runtime feeds a deliberately broken **in-memory**
copy to the invariant checker, the reachability verifier and the ruleset geometry check; the
R67/R68 audit is pointed at a synthetic tree containing a duplicate implementation; the codec
test shows Python's `json` accepting `NaN` by default before asserting the codec rejects it; the
§16 test shows the sign-flipped inclination crossing the disturbed threshold. No shipped
artifact is ever mutated (§37 rule 12).

## Physical tests that no CI run can satisfy

§25: "Physical devices only — simulators test UI and deterministic math, never sensor accuracy."
§37 rule 11 forbids marking physical accuracy, battery or thermal acceptance as passed from
simulator or emulator results. **Nothing in this repository has run on a phone.**
